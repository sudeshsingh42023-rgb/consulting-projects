# Consulting Projects

A collection of self-directed case studies applying business analysis, technical solutioning, and data-driven decision-making to real-world style problems. Built to practice the skills used in technology consulting: translating business objectives into recommendations, estimating cost and risk, and communicating findings clearly.

## Projects

### [Azure Solution Proposal](./azure-solution-proposal)
A mock pre-sales case study for a 12-store grocery client facing site outages, data loss, and a lean IT team. Proposes an Azure PaaS architecture (App Service autoscale, geo-redundant SQL Database, Front Door + CDN, Backup, Monitor), with a cost estimate, 10-week migration timeline, and risk mitigations.
**Tools:** Azure App Service, Azure SQL Database, Azure Front Door, Azure Monitor, Azure Pricing Calculator

### [Zomato Growth Case Study](./zomato-growth-case-study)
A business strategy case study identifying where a competitor was losing customer trust, using real user-reported complaints and reviews as research input. Prioritizes candidate problems using the RICE framework (Reach × Impact × Confidence ÷ Effort) to produce a defensible, data-backed recommendation.
**Tools:** Excel (weighted scoring, dashboards), Secondary Research, Data-Driven Prioritization
